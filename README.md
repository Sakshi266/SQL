## 📊 SQL 

This project contains SQL queries used for data cleaning, transformation, and analysis on a structured dataset. 
The goal is to demonstrate strong SQL skills using operations like GROUP BY, UPDATE, CASE, filtering, aggregation and date formatting.

### 🛠️ Technologies Used

MySQL

SQL Workbench / VS Code / Colab
### 📂 Project Overview

This SQL project includes:

✔ Data Cleaning

Handling NULL values

Updating inconsistent records

Standardizing date formats

✔ Data Transformation

Creating new calculated fields

Using CASE for categorization

Converting text to date

✔ Data Analysis

Grouping and aggregating data

Generating insights using COUNT, SUM, AVG

Analyzing trends and patterns

Filtering specific records
